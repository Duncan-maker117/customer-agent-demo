# 网页演示产品约定

## Register

Product：与桌面应用保持一致的客服管理演示，包含自动回复、关键词管理、账号管理、知识库、日志管理、设置和独立客服对话演示。

## Platform

Web：纯 HTML、CSS、JavaScript，适配桌面与手机，部署到 GitHub Pages。

## 用户与目标

项目体验者无需安装桌面应用或配置 API，即可在熟悉的桌面导航中体验账号状态、关键词维护、知识编辑、配置保存及对话。所有资料均为虚构；本地规则匹配不冒充大模型或真实平台服务。

## 体验约定

- 沿用 Duncan 发布者标识和现有轻氧棉 T 恤示例知识。
- 默认进入自动回复管理；聊天体验作为独立页面，不替代管理系统首页。
- 2026-10-22 用户明确要求还原桌面界面。采用浅灰左导航、青色主按钮、浅色内容区、账号卡片、表格和分组设置；以 `ui/main_ui.py` 与桌面截图为布局依据。
- 不添加营销标题、深色侧栏、聊天式首页或虚构业务指标。
- 仅使用本地静态资源，无字体 CDN、外部模型请求或客户数据上传。
- 状态保存在当前页面内存中，刷新即可重置；不写入浏览器存储。
- 键盘可操作，表单有标签，窄屏可完成主要流程，尊重减少动态效果设置。
